# PowerPoint Video Player

A video player for Microsoft PowerPoint using OpenGL, FFmpeg and NAudio.

## Features

- Video playback inside PowerPoint Slide Show.
- OpenGL-based rendering.
- Audio playback with synchronization.
- Playlist support.
- Previous and next video controls.
- Play and pause controls.
- Automatic playback of the next video.
- Controls that appear when hovering over the control area.
- FPS counter.

## Requirements

- Windows
- Microsoft PowerPoint 2019 or compatible version
- .NET Framework 4.8
- FFmpeg
- OpenTK 3.3.3
- NAudio 2.2.1

## Building

1. Clone this repository.
2. Open `PowerPointVideoPlayer.sln` in Visual Studio.
3. Restore NuGet packages.
4. Build the project.
5. Install the VSTO Add-in.

Make sure FFmpeg is available through PATH.
