# PowerPoint Video Player

Видеоплеер для Microsoft PowerPoint, использующий OpenGL, FFmpeg и NAudio.
## Языки
[English](README.md) | [Русский](README-ru.md)
## Возможности

- Воспроизведение видео непосредственно в режиме показа слайдов PowerPoint.
- Отрисовка видео с помощью OpenGL.
- Воспроизведение звука с синхронизацией.
- Поддержка плейлистов.
- Переключение на предыдущее и следующее видео.
- Управление воспроизведением и паузой.
- Автоматический переход к следующему видео.
- Панель управления, появляющаяся при наведении курсора на область управления.
- Счётчик FPS.

## Системные требования

- Windows.
- Microsoft PowerPoint 2019 или совместимая версия.
- .NET Framework 4.8.
- FFmpeg.
- OpenTK 3.3.3.
- NAudio 2.2.1.

## Сборка проекта

1. Клонируйте этот репозиторий.
2. Откройте файл `PowerPointVideoPlayer.sln` в Visual Studio.
3. Восстановите пакеты NuGet.
4. Соберите проект.
5. Установите надстройку VSTO.

Убедитесь, что FFmpeg доступен через переменную среды `PATH`.
